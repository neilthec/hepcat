# Two massive fermion pairs and positive-helicity photons

This research formula covers tree QED with two identical electrons, two
identical positrons and any number `N >= 0` of positive photons. All four
massive spin indices remain free. It is a direct current evaluator, separate
from `ConstructAmplitude`; no existing preparation/completion algorithm,
notebook, model or source module is changed.

## General representation

Use all-incoming labels `{e,E,E,e,photons}`, so the electrons are 1,4,
positrons 2,3 and photons 5 through `N+4`. Choose one common angle reference
`q` for the positive photons. The same scalar all-positive endpoint current
used in the one-minus representation is needed for each massive leg:

```math
J_{a,q}(\varnothing)=1,\qquad
J_{a,q}(S)=\frac{
 \sum_{i\in S}J_{a,q}(S\setminus\{i\})
 \langle q|p_a+\sum_{j\in S\setminus\{i\}}p_j|i]/\langle qi\rangle}
 {(p_a+\sum_{i\in S}p_i)^2-m^2}.
```

For an oriented electron/positron pair `a,b`, form its density and
momentum-weighted currents:

```math
C_{ab}(S)=\sum_{L\sqcup R=S}(-1)^{|R|}J_{a,q}(L)J_{b,q}(R),
```

```math
V_{ab}^{\mu}(S)=\sum_{L\sqcup R=S}(-1)^{|R|}J_{a,q}(L)J_{b,q}(R)
 \left(p_a+\sum_{i\in L}p_i\right)^{\mu}.
```

Write `P(v)=v0 I+v.sigma`, `barP(v)=adj P(v)`,
`barSigma^mu=(I,-sigma)`, and `k=-p_a-p_b-sum(S)`. The electromagnetic
current, stripped of its charge and external mass normalization, is

```math
B_{ab}^{\mu}(S)=\langle ab\rangle\left[
 2V_{ab}^{\mu}(S)-\sqrt2\sum_{i\in S}C_{ab}(S\setminus\{i\})\epsilon_i^{+\mu}
 \right]+C_{ab}(S)\langle a|\bar\Sigma^\mu\bar P(k)|b\rangle.
```

The complete amplitude is

```math
\mathcal M_N=\frac{e^2(-\sqrt2e)^N}{m^2}
 \sum_{S\sqcup T=P}\left[
 \frac{B_{12}(S)\cdot B_{43}(T)}{(p_1+p_2+\sum_{i\in S}p_i)^2}
 -\frac{B_{13}(S)\cdot B_{42}(T)}{(p_1+p_3+\sum_{i\in S}p_i)^2}\right].
```

The relative minus is the identical-fermion sign. There is no factor `1/2`:
the line containing electron 1 is always first, and each photon assignment
occurs once. Keep the pairings coherent before squaring. Phase-space symmetry
factors belong to the later observable, not this amplitude.

The term proportional to `epsilon_i` is essential. It is the two-photon
vertex generated by the exact second-order rewriting of the Dirac line;
one photon is the exchanged off-shell photon. It is not an independent QED
contact interaction. Contracting the sequential vertex with `k` gives the
difference of the two endpoint virtualities. The scalar recurrences reduce
that divergence to terms canceled precisely by this two-photon contribution.
All internal virtualities remain off shell, in numerators and denominators.

Sigma matrices can be eliminated with ordinary spinor identities. In
particular the two Pauli contributions, with exchanged momenta `k,-k`, have
contraction `-2 k^2 <ac><bd>`. Canceling that `k^2` against the photon
propagator creates an algebraically regular piece. It must be retained and
does not introduce an arbitrary new interaction.

This is a general recursive current formula, not a shortest closed product
or an AllPhysical representation. Its cached scalar work is
`O(N^2 2^N + 3^N)`, with `O(2^N)` storage. The full diagram count is
`(N+3)!/3`: 2, 8, 40, 240, 1,680 and 13,440 at `N=0,...,5`.

## Evaluate and validate

The Mathematica research helper is `tests/checks/fixtures/QED-four-fermion-all-plus-formula.wl`.
Load HEPCAT first, then that helper. It returns the normal
`{externalMassRules, expression}` pair and uses a momentum-dressed reference
by default, leaving no free Xi. The formulas and derivation are integrated
into the QED paper outline rather than a separate research document.

```wolfram
Get["~/code/hepcat/source/HEPCAT.wl"];
Get["~/code/hepcat/tests/checks/fixtures/QED-four-fermion-all-plus-formula.wl"];
model = ReadModel["~/code/hepcat/models", 3];
amplitude = QEDFourFermionAllPlusFormula[3,
  ModelParameter[model, "Me"], ModelParameter[model, "EE"]];
```

This example has four fermions and three positive photons, or seven external
particles. Run the focused symbolic regression directly:

```sh
WolframKernel -script tests/benchmarks/four-fermion-all-plus-symbolic-tests.wl
```

All 258 checks passed. They include seven generic matrix identities, exact
four-/five-/six-point model and fixture comparisons in all 16 massive-spin
components, both identical-fermion antisymmetries, photon Bose symmetry,
reference independence and off-shell current conservation. The external
rational charts do not impose an internal shell.

The C++ evaluator is `tests/benchmarks/four-fermion-all-plus-formulas.hpp`. Its
physical momenta are positive-energy `e- e+ -> e- e+ + N photons` with incoming
legs 1,2. It performs outgoing crossing once. Composite off-shell momenta are
ordinary matrices, never on-shell `particle` objects. The default reference
is a noncollinear null direction proportional to `p1|h]`, selected from the
external photons. An explicit common null-reference four-vector is optional.

Build against a matching SPINAS precision:

```sh
clang++ -O2 -std=c++11 -DWITH_LONG_DOUBLE \
  -I/path/to/spinas/include -Isource/internal/export \
  tests/benchmarks/four-fermion-all-plus-validation.cpp \
  /path/to/spinas/build/libspinas.a -o /path/to/validate
```

Create an independent MG reference using `source/internal/export/madgraph-runtime.py` as
described in `tests/benchmarks/README.md`, restricting interactions to electron and
photon, with all widths zero. The reference must match the chosen mass and
charge. Then run, for example:

```sh
/path/to/validate --photons 5 --points 1000 --mass 1 \
  --charge 0.3333333333333333333 --seed 2026110605 \
  --reference /path/to/reference/libhepcat_madgraph.dylib \
  --output /path/to/results/N5
```

All photons are fixed positive; both sides sum the squared moduli over the
16 massive-spin combinations without initial averages or final symmetry
factors. The default seed uses the time; an explicit seed replays the run.
Full momenta and all 16 complex amplitudes are saved, along with discrepancies.

The November 6 validation has 1,000 points at each `N=0,...,5`, all passing
MG, reference-change, photon-symmetry and coherent-current Ward checks.
The maximum MG discrepancy is `2.72e-11`. The tests include three new
multiplicities beyond the existing six-point catalog. Direct comparisons of
all 16 complex components with the known `N=0,1,2` expressions also pass at
100 points each, alternating masses and charges, without fitting a phase.

The Ward diagnostic uses the Frobenius norm of the complete two-spin current
tensor, retaining every component. A separate informational diagnostic
divides by each individual spin component, which can be very small. Its
original 53-bit runs had apparent failures at `N=4,5`; these remain archived.
True 64-bit-mantissa replays of the identical inputs reduce those maxima to
`2.12e-10` and `3.61e-9`. The final driver records both diagnostics. No
component or point is removed, and the acceptance threshold remains `1e-7`.

## Related primary work

- [Morgan, Second Order Fermions in Gauge Theories](https://arxiv.org/abs/hep-ph/9502230)
  explains the second-order vertices, including the required two-photon term.
- [Chalmers and Siegel, Simplifying Algebra in Feynman Graphs, Part I](https://arxiv.org/abs/hep-ph/9708251)
  develops the chiral formulation.
- [Lazopoulos, Ochirov and Shi, All-multiplicity amplitudes with four massive quarks and identical-helicity gluons](https://arxiv.org/abs/2111.06847)
  gives directly relevant massive-QCD results. Closed single-block primitives
  must not be Abelianized while omitting the other photon placements.

This symmetric QED representation needs a detailed comparison with the
published current formulations before any novelty claim.
